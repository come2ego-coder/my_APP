# 構成・執筆ルール
- 統計データ・調査結果などの具体的な数字を盛り込み、説得力を持たせる
- 紹介する項目・ステップは「簡単なもの→難しいもの」の順に並べる
- 冒頭は読者の悩みや不安に寄り添う共感パートから始める
- 文体は話し言葉（です・ます調、語りかけるトーン）で、専門用語を避け、使う場合は必ず平易に言い換える
- 読んだ後に読者が「今日からこれをやってみよう」と思える具体的な行動提案で締めくくる
- 有料部分にふさわしい、他では読めない実践的なノウハウや具体例を含める

1. タイトル（ターゲットに刺さる、悩み訴求型）

3. 統計データによる現状説明
