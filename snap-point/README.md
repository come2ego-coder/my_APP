# スタンプカード

飲食店向けの、来店ごとにスタンプが貯まるデジタルポイントカードアプリです。
レジのスマホ・タブレットにこの画面を開いておき、お客様が来店するたびに
一覧から名前を検索してスタンプを1つ押す、という使い方を想定しています。

- 「+ 新規登録」からお客様を名前(必須)と電話番号(任意)で登録します。
  会員証やQRコードは発行せず、スタッフが一覧から検索して選ぶだけで
  運用できます。
- 一覧の各お客様カードには現在のスタンプ数がスタンプの絵で表示され、
  「スタンプ +1」を押すたびに1つ増え、来店履歴に記録されます。
  押し間違えたときは「取消」で直前の1個を取り消せます。
- 設定した個数(初期値10個)貯まると「🎁 特典を渡す」ボタンに切り替わり、
  押すとスタンプ数がリセットされ、特典利用回数が加算されます。
- 名前をタップすると詳細画面が開き、スタンプ・累計スタンプ数・特典利用回数・
  来店履歴の一覧を確認できます。ここからお客様の削除もできます。
- 右上の⚙️「設定」から、お店の名前・特典に必要なスタンプ数・特典の内容
  (例: 1品サービス、ドリンク1杯無料)を自由に変更できます。
- 検索欄に名前や電話番号の一部を入力すると、その場で一覧が絞り込まれます。
  何も入力していないときは、前回来店が新しいお客様から順に並びます。
- 記録はすべてブラウザの `localStorage` に保存されます(サーバーには保存
  されません)。端末やブラウザを変えると記録は引き継がれないので、レジ端末
  は普段から同じ端末・同じブラウザを使うようにしてください。

## セットアップ

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000) を開くと使えます。外部APIキー
などの設定は不要です。

## Vercelへのデプロイ

1. このリポジトリ(このディレクトリ)をVercelにインポートする。
   - Root Directory に `snap-point` を指定する。
2. デプロイ後に発行されるURLをレジ端末のホーム画面に追加しておくと、
   アプリのようにワンタップで開けて便利です。

## 使ってみたときのイメージ

1. お客様が初めて来店したら「+ 新規登録」で名前を登録し、「スタンプ +1」
   を押す。
2. 次回以降は検索欄で名前を探し、該当のカードで「スタンプ +1」を押すだけ。
3. スタンプが設定した個数に達したら「🎁 特典を渡す」を押して特典を渡す。
   スタンプ数は自動的にリセットされ、また1から貯まっていく。
